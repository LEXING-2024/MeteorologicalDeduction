# 《气象推演》商店文案

## 一句话

> 你只负责气压差，剩下的交给大气。

## 短描述

> 在连续天气图上放置高压、低压、冷暖气团与水汽，按“风 → 上升/下沉 → 降水”三步结算，让每座城市出现你想要的天气。72 关战役，25 关现已开放。

## 长描述

《气象推演》是一款关于大气因果的 2D 解谜游戏。

你不直接“画”出雨，而是把气压差、气团和水汽放到天气图上，让风、垂直运动与降水自己发生。

冷锋为什么雨急？准静止锋为什么赖着不走？海风与谷风又如何被温差“长”出来？25 个可玩关卡，从单张牌的基础系统一路推到三城同时成立。

- **连续天气图**：等压线、温度场、风矢、锋面与降水叠加在同一张图上。
- **三步推演**：风场 → 上升/下沉 → 降水，每一步都参与结算。
- **真实物理直觉**：冷锋、暖锋、准静止锋、地形雨、海陆风、山谷风。
- **多目标关卡**：下雨、转晴、风向、温度、气压、连续降水，甚至一图三城。
- **可复盘**：失败会自动展开因果链，告诉你哪一步没有成立。

72 关战役，25 关现已开放，后续阶段持续更新。
