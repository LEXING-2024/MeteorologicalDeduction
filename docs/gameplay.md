# 《气象推演》玩法说明

## 一句话

把气压差、气团与水汽放到天气图上，按“风 → 上升/下沉 → 降水”的顺序推演，让城市出现目标天气。

## 核心循环

1. **读目标**：右侧面板会写明城市、判据与当前实况。
2. **放系统**：从左侧牌库拖拽卡牌到地图，或先点卡牌再点地图。
3. **调参数**：选强度档位；H/L 还可以拖动包围盒四角改变影响半径。
4. **运行推演**：按空格或点“运行推演”，依次结算风场、垂直运动、降水。
5. **读复盘**：成功后进入下一关；失败会展开因果链日志，告诉你哪一步没成立。

> 关键约束：**W ≤ 0 → R = 0**。没有上升运动，就不会有降水；湿区本身不是雨。

## 牌组

### 地面系统

| 卡牌 | 作用 | 常见用法 |
|---|---|---|
| 高压 H | 下沉、抑制凝结，局地气压升高 | 让城市转晴、压制锋面降水 |
| 低压 L | 抽吸、抬升，局地气压降低 | 制造上升运动与降水 |
| 冷气团 | 降温、抬高气压，密度大 | 与暖气团相遇形成冷锋 |
| 暖气团 | 升温、降低气压，密度小 | 与冷气团相遇形成暖锋 |
| 湿区 | 提供水汽 | 叠加在上升区/锋面上，突破饱和阈值 |

H/L 还可选择冷/暖变体；冷高压、暖高压、冷低压、暖低压的深浅层响应不同。

### 高空环境（后续阶段）

高空槽、高空脊、层结、急流会逐步开放，用来加深低压、抑制或放大上升运动。

## 三步结算

### 1. 风场

气压梯度驱动空气，湿区随低层风平移。北半球风向右偏，南半球向左偏；顶部“半球”按钮可以直接切换。

### 2. 上升 / 下沉

低压、锋面、地形迎风坡、切变线、干线等会抬升空气；高压、背风坡会抑制上升。城市面板里的 **W** 是综合上升速度。

### 3. 降水

只有上升且水汽越过饱和阈值才会成雨。降水率、24 小时等效雨量与雨量等级会一起结算。

## 目标类型

- 单点上升/下沉
- 增湿、降温、升温
- 指定城市转晴
- 出现指定锋面（冷锋/暖锋/准静止锋）
- 出现指定风向、风速
- 连续多回合维持降水
- 一张图上同时满足多座城市的不同天气

| 操作 | 说明 |

## 设计意图

《气象推演》不要求玩家背天气图，而是把“因果”做成可以亲手摆弄的积木：

- 为什么冷锋雨急？因为冷气团楔入，暖空气被陡峭抬升。
- 为什么准静止锋赖着不走？因为冷暖气团势均力敌，雨带停在原地。
- 为什么海风会从海面吹向陆地？因为白天陆地升温快、气压低。
- 为什么山谷风沿坡向上？因为山坡受热快，谷底空气被抽上去。

每一关只增加一个变量，让玩家在推演里自己得出答案。
