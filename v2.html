        怎么玩

        放置

        点击右侧要素卡，再点击地图落点。每回合最多一张，放置后自动演化 3 小时。

        气压卡改变气压场；低空急流会沿指定方向注入一条强风带。暖核与冷核的降水效率不同。

        回合

        每关 3–4 回合。没有放卡也可以“跳过本回合”。演化结束后自动判题，只给达成 / 未通过，没有星级。

        时间轴可回看任意小时；回看时不能继续放置，回到最右端即可操作。

        时间轴支持播放 / 暂停、1× / 2× / 4× 倍速和拖动滑块。播放只改变回看帧，不会跳过回合或重复消耗卡片。

        读图

        等压线是海平面实际气压（hPa，如 1004 hPa），低于 1000 hPa 为蓝色、高于 1000 hPa 为暖色。H / L 为闭合中心，虚线圆是等效半径。

        气温层用实际 2 m 气温色带并画等温线；站点数字是“实际气压 · 实际气温”。“体感”计入风寒与蒸发冷却，“温度平流”给出风把冷 / 暖空气搬运到该处的速率。

        风矢按风速着色；云与雨是当前小时场。滚轮缩放、拖动平移、双击复位。

        降水按当前格点占优相态着色：雨、雨夹雪、雪、冻雨、冰雹；站点卡显示累计水当量与相态。PW 由 1000 / 850 / 700 / 500 / 300 hPa 五层实际比湿积分（mm），不再用单层 q 的气候廓线冒充。

        850 / 700 / 500 hPa 温度是独立层场，不是地面温度加常数偏移；悬停读数会给出 850 / 500 hPa 层温。带层结的场景会按层温判相态。
